## Objective

Run the checks every Linux enumeration script starts with - sudo rights, SUID binaries, file capabilities, permissions of passwd/shadow/sudoers, writable PATH directories - and record the burst of find / getcap / sudo -l executions it leaves behind. Nothing is changed; the lists double as a hardening report for the host.

## Prerequisites

- Linux lab host with bash, find and (optionally) getcap
- auditd with execve logging and/or Sysmon for Linux

## Safety notes

- Runs only with --lab-confirmed on a disposable lab host you own
- Read-only; sudo is called with -n, so it never prompts for or uses a password
- Lists are saved to $RASD\_OUT\_DIR for review and contain no secrets
