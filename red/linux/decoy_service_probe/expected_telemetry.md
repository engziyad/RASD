## Logging that must be enabled

- Decoy host: OpenCanary file logger to /var/tmp/opencanary.log (deceive/opencanary/settings.json), forwarded as the opencanary/honeypot log source
- Portscan module: iptables LOG rules to the kernel log, as the OpenCanary documentation describes, for SYN and Nmap records

If an event is missing, check it in this order: the audit policy or Sysmon configuration that writes it, the collector that forwards it, and the parser that maps its fields (`rasd doctor <export>` checks the last two).
