# HKCU Run value pointing into a user-writable folder

|---|---|

## Objective

Write a per-user Run value that would start a binary from %LOCALAPPDATA%\\Temp at the next logon - the most common user-level persistence - and prove the Sysmon registry event fires the Run-key detection. The referenced file does not exist and the value is removed before anyone logs on again.

## Prerequisites

- Windows 10/11 lab VM with Sysmon whose configuration logs Run-key writes (Event ID 13)

## Safety notes

- Runs only with -LabConfirmed on a disposable lab VM you own
- Writes one value named after the run marker; the binary it points to does not exist
- Standard user rights only (HKCU)

## Execution

1. New-ItemProperty HKCU:\\Software\\Microsoft\\Windows\\CurrentVersion\\Run -Name &lt;marker&gt; -Value $env:LOCALAPPDATA\\Temp\\&lt;marker&gt;.exe
2. collect\_artifacts.ps1 saves the value (name and data only, not the user's other Run entries)
3. cleanup.ps1 removes the value and confirms it is gone
