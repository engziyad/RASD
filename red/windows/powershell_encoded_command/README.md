## Objective

Prove that an encoded PowerShell command line reaches the SIEM intact and fires the encoded-command detection. The payload only writes the run marker to the console, so the test proves the telemetry path without executing anything harmful.

## Prerequisites

- Windows 10/11 or Windows Server lab VM with Sysmon (Event ID 1) installed
- PowerShell script block logging (Event ID 4104) enabled to capture the decoded script

## Safety notes

- Runs only with -LabConfirmed on a disposable lab VM you own
- The decoded payload is Write-Output '&lt;marker&gt;'; it creates no file, task, key or network connection
- Nothing persists, so cleanup only verifies that no process carrying this run's Base64 payload is still running

## Execution

1. Run the step through the runner so the marker, timing and cleanup are recorded
2. The runner starts a child powershell.exe with -NoProfile -enc &lt;Base64 of the payload&gt;
3. Export telemetry with Export-LabTelemetry.ps1 and run `rasd evidence`
