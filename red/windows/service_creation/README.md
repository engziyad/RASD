## Objective

Install a Windows service whose binary path is a cmd.exe /c command line - the shape PsExec-style tools and Impacket leave behind - and prove the System 7045 event reaches the SIEM with ServiceName and ImagePath intact. The service is created with start=demand and is never started.

## Prerequisites

- Windows 10/11 or Windows Server lab VM, elevated PowerShell
- System event log collected (7045 is written by the Service Control Manager)

## Safety notes

- Runs only with -LabConfirmed on a disposable lab VM you own
- The service is never started; its command would only echo the marker
- The service name is the run marker, so cleanup can only delete what this test created

## Execution

1. sc.exe create &lt;marker&gt; binPath= "cmd.exe /c echo &lt;marker&gt;" start= demand
2. collect\_artifacts.ps1 saves sc.exe qc output and the service registry key as JSON
3. cleanup.ps1 deletes the service and confirms sc.exe query no longer finds it
