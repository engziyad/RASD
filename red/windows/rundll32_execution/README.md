## Objective

Launch rundll32.exe with the javascript: / mshtml RunHTMLApplication trick that malware uses to run script through a signed Windows binary, and prove the process-creation event fires the rundll32 detection. The script only assigns the run marker and calls close(), so the process exits immediately.

## Prerequisites

- Windows 10/11 or Windows Server lab VM with Sysmon (Event ID 1) installed

## Safety notes

- Runs only with -LabConfirmed on a disposable lab VM you own
- The JavaScript payload assigns the run marker and calls close(); nothing is downloaded, written or executed beyond rundll32 itself
- Endpoint protection may terminate rundll32; the process-creation event is still written and the step still counts

## Execution

1. Start-Process rundll32.exe -ArgumentList 'javascript:"\\..\\mshtml,RunHTMLApplication ";var m=''&lt;marker&gt;'';close();'
2. cleanup.ps1 confirms no rundll32 process carrying this run's marker is left
