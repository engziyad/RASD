## Objective

Run the read-only LDAP queries that precede most AD attacks - every user with an SPN, members of Domain Admins, every computer - and measure whether the environment records them at all. The test prints counts only. RASD has no rule for this yet; the run tells you whether the telemetry a rule would need exists.

## Prerequisites

- Domain-joined lab workstation, ordinary domain user
- To see the queries on the DC: Directory Service diagnostics '15 Field Engineering' = 5 with the expensive/inefficient search thresholds lowered (event 1644), or EDR LDAP telemetry

## Safety notes

- Runs only with -LabConfirmed
- Read-only LDAP searches; prints counts, never names or attributes
- Nothing is written anywhere

## Execution

1. (servicePrincipalName=\*) on user objects - the Kerberoasting target list
2. (memberOf=CN=Domain Admins,...) - the privileged users
3. (objectCategory=computer) - the host inventory
