## Objective

Replay a lab account's genuine token against a protected endpoint, then the same token re-encoded with alg none and no signature, then with a changed payload and the original signature. A server that accepts either forged token lets anyone mint identities.

## Prerequisites

- A lab copy of the application on localhost or a private address (for example OWASP Juice Shop)
- A lab test account, given to the test as RASD\_LAB\_EMAIL / RASD\_LAB\_PASSWORD environment variables

## Safety notes

- Runs only with --lab-confirmed; refuses any target that resolves to a public address
- Three read-only GET requests after one login
- Forged tokens are built in memory and never written to disk

## Execution

1. export RASD\_LAB\_EMAIL=alice@lab.local RASD\_LAB\_PASSWORD=...
2. python3 red/run\_red.py --test jwt\_testing --lab-confirmed --target http://127.0.0.1:3000
