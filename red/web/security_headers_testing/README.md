## Objective

Read the browser protections the application sets on its start page - HSTS, Content-Security-Policy, X-Content-Type-Options, clickjacking protection, Referrer-Policy, Permissions-Policy and cookie flags - and list what is missing. This is a configuration review: it produces a findings list for the application owner, not attack telemetry.
