## Objective

Check that every protected API endpoint refuses a request with no token, a malformed token, and a well-formed JWT signed with a key the server never issued - and generate the 401/403 burst that an attacker probing an API leaves in the web logs, which the API-probing correlation must catch.

## Prerequisites

- A lab copy of the application on localhost or a private address (for example OWASP Juice Shop)
- Python 3.9+ on the machine running the test (standard library only)
- Web server or reverse-proxy access logs collected (combined log format or JSON)

## Safety notes

- Runs only with --lab-confirmed; refuses any target that resolves to a public address
- Read-only GET requests, paced at 5 per second
- Malformed tokens can crash fragile applications: OWASP Juice Shop 17.3.0 terminates on a malformed JWT at /api/Deliverys, so that path is not in the defaults

## Execution

1. python3 red/run\_red.py --test api\_auth\_testing --lab-confirmed --target http://127.0.0.1:3000
2. Each endpoint is called three times (no token, malformed token, foreign-signed JWT)
3. Results print as PASS / FINDING / REVIEW and are saved as JSON for the runner
