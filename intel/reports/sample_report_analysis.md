## Source Summary
On 5 October 2026 a user on WS07 opened a Word document that launched hidden, encoded PowerShell. Within twenty-two minutes the intruder set up two kinds of persistence, dumped LSASS with a built-in DLL, sprayed one password at nine domain accounts, Kerberoasted four service accounts, cleared the Security log and installed a remote-execution service on the file server SRV-FS01.

## Hunting Logic
- Encoded PowerShell whose parent is an Office application, joined to network connections from the same PID.
- Any host where a task **and** a Run key reference the same binary within minutes.
- Workstations requesting RC4 tickets for three or more user-based SPNs in ten minutes.
- Sources that fail authentication for many accounts over hours, below the correlation's 10-minute threshold.
- 7045 on a server within minutes of Kerberoasting from a workstation that authenticated to it.

## Required Telemetry
- Process creation with command line (Sysmon 1)
- Registry value set for autostart keys (Sysmon 13)
- Process access to lsass.exe (Sysmon 10)
- Domain controller Kerberos service ticket auditing (4769) and authentication failure auditing (4771, 4625)
- Security and System logs forwarded off the host (1102 / 104, 7045)

## SOC Action
Every behaviour in this intrusion is detected and every detection is backed by a red test and a DFIR playbook; the correlated storyline turns twelve alerts into one incident. The remaining work is operational: run the red tests in the lab and commit the evidence, so the Operational Score stops being pending.
