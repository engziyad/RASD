# Purple Scenario: Service Execution (T1569.002 System Services: Service Execution)

## Objective
Validate that a service installed with a command-interpreter binary path is recorded by the Service Control Manager and fires the service-installation detection.

## Red
Run `service_creation`: `sc.exe create <marker> binPath= "cmd.exe /c echo <marker>" start= demand`. The service is never started.

Test folder: [`red/windows/service_creation`](../../red/windows/service_creation/) · expected telemetry: [expected_telemetry.md](../../red/windows/service_creation/expected_telemetry.md)

## Telemetry
- System 7045 - ServiceName, ImagePath, AccountName
- Security 4697 - installing account (if audited)
- Sysmon 13 - ImagePath under the Services key

## Detect
- [`T1569.002_suspicious_service_installation`](../../detect/detections/T1569.002_suspicious_service_installation/) - rule, tests, mutation tests, KQL and SPL

Run the full gate for these detections:

```bash
rasd test --filter T1569.002
rasd prove --filter T1569.002
rasd parity --filter T1569.002
```

## DFIR
Playbook: [service_installation.md](../../dfir/playbooks/service_installation.md). Collect:
- Service configuration
- Network logon (4624 type 3) before the install, when remote
- Share access (5140/5145)
- Service binary

## Intel
PsExec-style remote services are a staple of ransomware operators' lateral movement. Groups: Wizard Spider (G0102) - [actor tradecraft map](../../intel/mappings/actor_tradecraft_map.md).

- The service configuration was saved before cleanup deleted the service
