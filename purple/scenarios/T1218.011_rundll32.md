# Purple Scenario: Rundll32 Proxy Execution (T1218.011 System Binary Proxy Execution: Rundll32)

## Objective
Validate that rundll32 running script through mshtml (`javascript:` / RunHTMLApplication) is caught from the process-creation event alone.

## Red
Run `rundll32_execution`: `rundll32 javascript:"\..\mshtml,RunHTMLApplication ";var m='<marker>';close();` - the script only sets the run marker and closes itself.

Test folder: [`red/windows/rundll32_execution`](../../red/windows/rundll32_execution/) · expected telemetry: [expected_telemetry.md](../../red/windows/rundll32_execution/expected_telemetry.md)
