# Purple Scenario: Unix Shell (T1059.004 Command and Scripting Interpreter: Unix Shell)

## Objective
Validate that a Base64 command piped into a shell and a script run from /tmp are recorded by Sysmon for Linux and fire the Linux shell-execution rule.

## Red
Run `suspicious_shell_execution`: `sh -c "echo <blob> | base64 -d | sh"`, then a script written to `/tmp/<marker>.sh` and run from there. Both only print the run marker; cleanup removes the script.

Test folder: [`red/linux/suspicious_shell_execution`](../../red/linux/suspicious_shell_execution/) · expected telemetry: [expected_telemetry.md](../../red/linux/suspicious_shell_execution/expected_telemetry.md)

## Telemetry
- Sysmon for Linux 1 - `sh -c ... | base64 -d | sh` and `/bin/sh /tmp/<marker>.sh`
- Sysmon for Linux 11 - the script written to `/tmp`
- auditd EXECVE - one record per process, when auditd is configured
