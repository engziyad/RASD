# Purple Scenario: T1070.001 Event Log Clearing

## Objective
Validate the three layers of log-clearing detection: the clearing command, the System 104 record and - when opted in - the Security 1102 record.

## Red
Run `event_log_clearing`: create a test log named after the marker and clear it with wevtutil; optionally (`-IncludeSecurityLogClear`) back up and clear the Security log.

Test folder: [`red/windows/event_log_clearing`](../../red/windows/event_log_clearing/) · expected telemetry: [expected_telemetry.md](../../red/windows/event_log_clearing/expected_telemetry.md)

## Telemetry
- Sysmon Event ID 1 - wevtutil.exe cl <log>
- System 104 - Microsoft-Windows-Eventlog, the cleared channel
- Security 1102 - audit log cleared (opt-in step)
