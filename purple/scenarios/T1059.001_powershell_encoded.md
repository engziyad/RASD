# Purple Scenario: Encoded PowerShell (T1059.001 Command and Scripting Interpreter: PowerShell)

## Objective
Validate that an encoded PowerShell command line is logged in full, reaches the SIEM, fires the encoded-command detection and leads an analyst to the decoded payload.

## Red
Run `powershell_encoded_command`: a child powershell.exe with `-NoProfile -enc` and a payload that only writes the run marker.

Test folder: [`red/windows/powershell_encoded_command`](../../red/windows/powershell_encoded_command/) · expected telemetry: [expected_telemetry.md](../../red/windows/powershell_encoded_command/expected_telemetry.md)

## Telemetry
- Sysmon Event ID 1 - Image powershell.exe, CommandLine with `-enc <Base64>`
- PowerShell 4104 - the decoded script block with the marker
- Security 4688 when command-line auditing is on

## Detect
- [`T1059.001_powershell_encoded_command`](../../detect/detections/T1059.001_powershell_encoded_command/) - rule, tests, mutation tests, KQL and SPL

Run the full gate for these detections:

```bash
rasd test --filter T1059.001
rasd prove --filter T1059.001
rasd parity --filter T1059.001
```

## DFIR
Playbook: [suspicious_powershell.md](../../dfir/playbooks/suspicious_powershell.md). Collect:
- Decoded command (Base64, UTF-16LE)
- 4104 script block
- Parent process tree
- Network connections of the PowerShell PID

## Intel
PowerShell loaders and encoded commands are standard tradecraft; the actor map lists groups whose published procedures include it. Groups: MuddyWater (G0069), APT29 (G0016) - [actor tradecraft map](../../intel/mappings/actor_tradecraft_map.md).
