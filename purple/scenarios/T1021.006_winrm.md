# Purple Scenario: Windows Remote Management (T1021.006 Remote Services: Windows Remote Management)

## Objective
Validate that a command run on another host over WinRM is recorded on the target as a child of the session host, and that the WinRM child-process detection fires on it.

## Red
Run `winrm_access_validation`: `Invoke-Command` against a lab target runs `cmd.exe /c echo` with the run marker. Nothing is created on either host.

Test folder: [`red/active_directory/winrm_access_validation`](../../red/active_directory/winrm_access_validation/) · expected telemetry: [expected_telemetry.md](../../red/active_directory/winrm_access_validation/expected_telemetry.md)

## Telemetry
- Target Security 4624 (type 3) - the network logon of the session
- Target WinRM Operational 91 - the remote shell
- Target Sysmon 1 - `wsmprovhost.exe` started by svchost, then `cmd.exe` started by `wsmprovhost.exe`
