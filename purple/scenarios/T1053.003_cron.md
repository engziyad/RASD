# Purple Scenario: Cron (T1053.003 Scheduled Task/Job: Cron)

## Objective
Validate that a cron table installed from standard input is recorded by Sysmon for Linux and fires the crontab rule.

## Red
Run `cron_persistence`: the script reads the current table with `crontab -l`, then installs it again with one harmless line through `crontab -`. Cleanup removes exactly that line.

Test folder: [`red/linux/cron_persistence`](../../red/linux/cron_persistence/) · expected telemetry: [expected_telemetry.md](../../red/linux/cron_persistence/expected_telemetry.md)

## Telemetry
- Sysmon for Linux 1 - `crontab -` with its parent chain
- syslog or journald - `crontab[pid]: (<user>) REPLACE (<user>)`
- auditd - the crontab execution and the spool file write, when auditd is configured
