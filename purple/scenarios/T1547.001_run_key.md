# Purple Scenario: T1547.001 Run Key Persistence

## Objective
Validate that a per-user Run value pointing into a user-writable folder is logged by Sysmon and fires the Run-key detection.

## Red
Run `run_key_persistence`: a HKCU Run value named after the marker pointing to `%LOCALAPPDATA%\Temp\<marker>.exe` (the file does not exist).

Test folder: [`red/windows/run_key_persistence`](../../red/windows/run_key_persistence/) · expected telemetry: [expected_telemetry.md](../../red/windows/run_key_persistence/expected_telemetry.md)
