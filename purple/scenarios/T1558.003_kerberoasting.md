# Purple Scenario: Kerberoasting (T1558.003 Steal or Forge Kerberos Tickets: Kerberoasting)

## Objective
Validate that a service-ticket request for an RC4-enabled service account is logged by the domain controller and fires the Kerberoasting detection.

## Red
Run `kerberoasting -Spn <lab SPN>`: one ticket request through KerberosRequestorSecurityToken; nothing is exported or cracked.

Test folder: [`red/active_directory/kerberoasting`](../../red/active_directory/kerberoasting/) · expected telemetry: [expected_telemetry.md](../../red/active_directory/kerberoasting/expected_telemetry.md)
