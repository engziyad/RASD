# Purple Scenario: LSASS Access (T1003.001 OS Credential Dumping: LSASS Memory)

## Objective
Validate that an LSASS dump with the built-in comsvcs.dll is caught twice - by the process access to LSASS and by the rundll32 command line.

## Red
Run `lsass_memory_access` (opt-in `-IncludeCredentialAccess`): `rundll32 comsvcs.dll, MiniDump <lsass PID> %TEMP%\<marker>.dmp full`; the dump is hashed and deleted.

Test folder: [`red/windows/lsass_memory_access`](../../red/windows/lsass_memory_access/) · expected telemetry: [expected_telemetry.md](../../red/windows/lsass_memory_access/expected_telemetry.md)

## Telemetry
- Sysmon Event ID 10 - SourceImage rundll32.exe, TargetImage lsass.exe, read-capable GrantedAccess
- Sysmon Event ID 1 - comsvcs.dll MiniDump command line
- Sysmon Event ID 11 - the .dmp file
