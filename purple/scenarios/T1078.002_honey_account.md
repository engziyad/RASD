# Purple Scenario: Honey Account Use (T1078.002 Valid Accounts: Domain Accounts)

## Objective
Validate that one authentication attempt with a decoy domain account - the credential an attacker takes from a lure - is logged by the domain controller and fires the honey account detection, with no outcome or source filter in the way.

## Red
Run `honey_account_use`: the first step binds to the lab domain as `svc_backup_adm` with a random wrong password (one LDAP bind, as the password spray simulation does), after checking that the account carries the decoy's description and has room before lockout.

Test folder: [`red/active_directory/honey_account_use`](../../red/active_directory/honey_account_use/) · expected telemetry: [expected_telemetry.md](../../red/active_directory/honey_account_use/expected_telemetry.md)

Decoys must be deployed first: `deceive\Deploy-RasdDecoys.ps1 -LabConfirmed -Accounts` ([inventory](../../deceive/decoys.yml)).

## Telemetry
- DC Security 4771 - TargetUserName `svc_backup_adm`, Status 0x18, IpAddress of the workstation (Kerberos), or 4776 and 4625 on NTLM fallback

## Detect
- [`T1078.002_honey_account_authentication`](../../detect/detections/T1078.002_honey_account_authentication/) - rule, tests, mutation tests, behaviour proof, KQL and SPL

Run the full gate for this detection:

```bash
rasd prove --filter T1078.002
rasd certify --filter T1078.002
rasd parity --filter T1078.002
rasd deceive --check
```

## DFIR
Playbook: [honey_account_use.md](../../dfir/playbooks/honey_account_use.md). Collect:
- The alert event with the source address or workstation
- The authentication burst from the source (a spray or roasting run around the decoy)
- The decoy's attributes at run time (collect_artifacts.ps1)

## Intel
Compromised domain accounts are how most documented intrusions move: the groups RASD tracks that ATT&CK documents using domain accounts are in the [actor tradecraft map](../../intel/mappings/actor_tradecraft_map.md) (Wizard Spider G0102, Volt Typhoon G1017, OilRig G0049). A decoy account is caught by the same behaviour whoever performs it.
