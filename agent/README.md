# RASD-Agent

The counsel: what to do next, computed from what the repository proves, for the analyst, the detection engineer, the purple team and the executive. Design and commands: [docs/AGENT.md](../docs/AGENT.md).

| File | What it is |
|---|---|
| [`ADVICE.md`](ADVICE.md) | The counsel on the repository, every role, ranked, with the ledger of decisions. Generated by `rasd advise --write` on every build; `rasd advise --check` fails CI when it is stale |
| [`decisions.yml`](decisions.yml) | The decisions people took on the findings (`rasd advise --decide`): accepted, rejected with a reason, deferred until a date, applied from a proposal. The agent ranks accordingly and counts what was resolved |
| `proposals/` | Drafts written by `rasd advise --propose <id>`, each verified before it is written: `PROPOSAL.md` and the files to apply under `files/`. Local work, ignored by git; `--apply` copies them into the tree and runs the gates |
| `environment.yml` | Written by `rasd advise --logs <export> --learn`: counts and verdicts of your own telemetry, never a value from a log. Local, ignored by git |

```bash
rasd advise                       # every role
rasd advise --for engineer        # one role
rasd advise --logs export.jsonl   # your own telemetry
rasd advise --explain T1078.002 --event alert.json
rasd advise --propose backlog.T1083
```
